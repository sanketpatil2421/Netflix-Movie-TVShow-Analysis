#  🚀Features

✔️ Cleaned and processed Netflix dataset

✔️ Exploratory Data Analysis (EDA) with visual insights

✔️ Genre & Rating distribution analysis

✔️ Country-wise content trends

✔️ Year-wise release analysis

✔️ Most frequent actors, directors, and categories

✔️ Beautiful visual dashboards (Matplotlib / Seaborn / Plotly)

✔️ Interactive web app (Streamlit) (optional)   


# ▶️ Installation & Run Instructions
cd netflix-analytics; python -m streamlit run app.py

## 📘 Dataset

Source: Netflix Movies and TV Shows Dataset
Columns include:
show_id, type, title, director, cast, country, date_added, release_year, rating, duration, listed_in, description

🔍 Analysis Performed

1️⃣ Content Type Distribution
Percentage of Movies vs TV Shows

2️⃣ Release Year Trend
When Netflix added the most content
Peak years of movie/series production

3️⃣ Genre / Category Analysis
Most frequent genres on Netflix

4️⃣ Country-wise Analysis
Countries producing the most Netflix content

5️⃣ Rating Classification
Rating distribution (TV-MA, PG-13, R, etc.)

6️⃣ Cast & Director Analytics
Most frequent actors and directors
Collaboration networks (optional)
